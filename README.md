# 常驻城市时钟

用静态 HTTP 服务器打开 `index.html`（例如 `python -m http.server 8765`），然后访问 `http://127.0.0.1:8765/index.html`。

## 设置城市

点击右下角「配置」，分别设置左侧和右侧城市：

1. 输入两位国家代码，例如 `NZ`、`CN`、`US`。
2. 输入城市英文名，点击「搜索城市」或在搜索框按 Enter。
3. 根据省／州和国家选择候选地点。城市和城镇优先展示，选择后立即保存。

原有布局中显示中文城市名、英文名、日期与星期、当地时间、中文时间名称及实际 UTC 偏移。Open-Meteo / GeoNames 未提供中文译名时保留原名，并在配置中提示。左右地点保存到浏览器本地存储。

左侧城市作为防熬夜、就寝恢复和喝水清零的时间基准；切换地点保留喝水次数，重新确定当前喝水日和就寝恢复时间。测试模式模拟左侧城市的当地时间，不修改真实城市配置。

## 时间同步

城市查询使用 Open-Meteo Geocoding；时间和当前 UTC 偏移使用 TimeAPI.io；中文时间名称使用浏览器 Intl。均无需 API Key，需能连接这两个服务。

启动时、每 30 分钟及页面恢复可见／网络恢复时同步。两座城市共用网络校准的 UTC 时间，本地使用单调计时持续走秒。配置中的「重新同步网络时间」可立即重试。

从未同步成功时暂用电脑时间；同步成功后网络故障沿用已校准时间。同步状态在配置中显示。免费服务的可用性及中文译名完整度不由本项目保证，中文时间名称和提醒换算依赖浏览器的时区数据库。
